# 🏟️ Kongo Arena

Plataforma de gestão esportiva.

## 🚀 Acesso

- `admin.html` - Painel Admin
- `cliente.html` - Área do Cliente
- `login.html` - Login/Registro

## 🛠️ Stack

- PHP 8.5+
- MySQL
- API REST + JWT
- HTML/CSS/JS

## 📦 Instalação

1. Clone o repositório
2. Configure `api/config/database.php`
3. Configure `api/config/jwt.php`
